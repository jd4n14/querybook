## Findings considered and rejected

- Adding snapshots, DDL lookup, semantic diffs, or schema browsing: outside the
  approved migration and would obscure transport regressions.
- Sharing one daemon between Neovim instances: adds discovery, authentication,
  and cross-editor lifecycle problems without value for the current local plugin.
- Adding persistent SQL sessions in v1: transaction/reconnect semantics need a
  separate product decision; isolated executions are explicit and testable.
- Shipping CGo SQLite or an automatic binary downloader: complicates portable
  local builds and trust/update behavior; use a CGo-free pinned driver and an
  explicit plugin-manager build hook for this migration.
- Adding a release workflow before protocol stabilization: defer checksummed
  platform binaries until the runner interface has survived this migration.
