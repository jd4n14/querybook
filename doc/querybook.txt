CONTENTS                                                        *querybook.contents*

                                                        *Querybook*
Querybook keeps SQL in the current buffer and renders each execution below its
statement using virtual lines. Results remain independent when another
statement is run.

COMMANDS                                                        *querybook-commands*

:QuerybookRun                                                     *:QuerybookRun*
    Run the statement under the cursor. In visual mode, run the selected SQL;
    multiple statements receive independent result anchors. Use :QuerybookRun!
    to explicitly allow a write blocked by the basic safety guard.

:QuerybookInspect                                             *:QuerybookInspect*
    Open the retained result in a vertical scratch view. The view requests
    handle based pages from the runner and includes execution SQL, profile,
    driver, database, matching/source row positions, and full field values.

:QuerybookFilter                                               *:QuerybookFilter*
    Prompt for a JSONPath or shorthand expression and apply it to every retained
    row. Invalid expressions leave the prior view unchanged. An empty expression
    clears the filter.

:QuerybookClearFilter                                     *:QuerybookClearFilter*
    Clear the inspector filter and return to all retained rows.

:QuerybookPinRow                                             *:QuerybookPinRow*
    Pin the current source row, or unpin it when it is already pinned.

:QuerybookCompareRows                                   *:QuerybookCompareRows*
    Compare the current row with the pinned row using positional columns and
    structural JSON comparison supplied by the runner.

:QuerybookExportRetained                             *:QuerybookExportRetained*
:QuerybookExportFiltered                             *:QuerybookExportFiltered*
:QuerybookExportFull                                      *:QuerybookExportFull*
    Prompt for a format and a new path, then export the explicitly selected
    retained, filtered, or full scope. Progress is reported with an export ID.

:QuerybookRefresh                                             *:QuerybookRefresh*
    Re-run the statement under the cursor with the active connection.

:QuerybookToggle                                             *:QuerybookToggle*
    Collapse or expand only the result attached to the statement under the
    cursor. Inspection remains available while a result is collapsed.

:QuerybookNextPage                                         *:QuerybookNextPage*
    Show the next page of retained rows for the result under the cursor.

:QuerybookPrevPage                                         *:QuerybookPrevPage*
    Show the previous page of retained rows for the result under the cursor.

:QuerybookNextColumn                                     *:QuerybookNextColumn*
    Show the next page of retained columns for the result under the cursor.

:QuerybookPrevColumn                                     *:QuerybookPrevColumn*
    Show the previous page of retained columns for the result under the cursor.

:QuerybookClear                                                   *:QuerybookClear*
    Clear the result attached to the statement under the cursor.

:QuerybookClear!                                                  *:QuerybookClear!*
    Clear every result in the current SQL buffer.

:QuerybookConnections                                      *:QuerybookConnections*
    Open the native connection manager. The qC normal-mode mapping opens the
    same list; qc remains the clear mapping. Enter selects a connection, a adds
    one, e edits metadata, p changes its password, d deletes after confirmation,
    t tests a saved connection, and q closes the list.

:QuerybookConnectionsImport                           *:QuerybookConnectionsImport*
    Explicitly copy the metadata allowlist from a named legacy config profile
    into the connection form. Password fields are ignored; save prompts for a
    new password when the selected driver is MySQL.

INSPECTOR                                                     *querybook-inspector*

In a QuerybookInspect scratch window, use these normal-mode mappings:

    [r / ]r      Move to the previous or next matching row.
    [p / ]p      Move to the previous or next matching page.
    Enter / za   Expand or collapse the JSON node under the cursor lazily.
    gR           Toggle raw/formatted display for the current field.
    K            Show the actual source column metadata (type and nullable).
    gQ           Show the full execution SQL when the compact header truncates it.
    yv          Copy the exact field value under the cursor. SQL NULL is copied
                as the textual marker NULL; row and payload copies retain its
                null type.
    yr          Copy the current row as ordered JSON, preserving values as
                strings and SQL NULL as JSON null.
    yp          Copy the complete result payload as ordered JSON.
    q           Close the inspector window.

JSON fields are expanded lazily only when their column metadata identifies a
structured type. Copy operations use retained typed cells, so tabs, newlines,
Unicode, decimals, and large integers are not rounded or clipped. A stale
result continues to show its captured SQL and connection snapshot; a new
successful execution creates a fresh handle and clears inspector state.

CONFIGURATION                                                  *querybook-config*

Connections are managed by the Go runner and selected by a persisted UUID.
The native metadata form accepts name, driver, host, port, database, username,
socket, path, and charset. SQLite requires path. Passwords are captured only
for create and password-change actions through a hidden prompt and are sent
immediately over the private stdin request; they are never displayed or kept
in Lua state. Results capture the selected connection profile and database
when they execute; changing the active connection does not rewrite existing
result metadata.

The inline display reads these limits, while retaining the complete result:

    preview_rows           Rows per inline viewport page (default 10)
    max_rows               Legacy alias for preview_rows when preview_rows is absent
    max_columns            Columns per inline viewport page (default 12)
    max_value_length       Legacy cell-length hint; cells clip to the window
    max_column_width       Legacy cell-width hint; the last column flexes to fill
                           the current window

    runner_path             Optional installed querybook-runner executable
    connection_store_path   Optional managed metadata SQLite path
    timeout_ms              Query timeout (default 30000)
    max_retained_rows       Runner retention bound (default 10000)
    max_retained_bytes      Runner retention bytes (default 16 MiB)
    batch_rows              JSONL batch row bound (default 200)
    batch_bytes             JSONL batch byte bound (default 512 KiB)

The inline result table fills the current window width and clips cells to
fit. Hidden row and column pages are labelled with the current range, and
QuerybookInspect remains available for the full result. Top-level SELECT
statements without an outer LIMIT receive a Go-runner `LIMIT 500`; explicit
outer limits and nested or commented LIMIT text are preserved. The inline
header reports this automatic limit separately from the visible row page and
retention status.

TRANSPORT                                                     *querybook-transport*

The Go child speaks protocol v1 JSONL. Rows are positional arrays and columns
are ordered metadata objects. NULL, text, and base64 binary cells remain
lossless, including duplicate labels and exact numeric text. Sessions are
isolated per execution. Unforced reads use driver-enforced read-only boundaries;
use :QuerybookRun! for explicit writes.
